# Rayenergy SDK 2.0.0

This repository distributes the Web, Android, iOS and Flutter SDKs.
Use the exact version URLs in [sdk-release.json](sdk-release.json) for reproducible builds.

- Web: `npm install --save-exact https://raw.githubusercontent.com/rayenergytech/rayenergy-mp-sdk/v2.0.0/npm/rayenergytech-mp-web-sdk-2.0.0.tgz`
- Android: add `https://raw.githubusercontent.com/rayenergytech/rayenergy-mp-sdk/v2.0.0/maven` to Gradle Maven repositories and depend on `com.rayenergytech:mp-tracker-android:2.0.0`.
- iOS: add this Git repository as a Swift package and select version `2.0.0` and the `MpTracker` product.
- Flutter: add a Git dependency to this repository with path `flutter/mp_tracker` and ref `v2.0.0`.
