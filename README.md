# Rayenergy SDK 1.5.11

This repository distributes the Web, Android, iOS and Flutter SDKs.
Use the exact version URLs in [sdk-release.json](sdk-release.json) for reproducible builds.

- Web: `npm install --save-exact https://raw.githubusercontent.com/rayenergytech/rayenergy-mp-sdk/v1.5.11/npm/rayenergytech-mp-web-sdk-1.5.11.tgz`
- Android: add `https://raw.githubusercontent.com/rayenergytech/rayenergy-mp-sdk/v1.5.11/maven` to Gradle Maven repositories and depend on `com.rayenergytech:mp-tracker-android:1.5.11`.
- iOS: add this Git repository as a Swift package and select version `1.5.11` and the `MpTracker` product.
- Flutter: add a Git dependency to this repository with path `flutter/mp_tracker` and ref `v1.5.11`.
